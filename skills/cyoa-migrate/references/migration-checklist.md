# Migration checklist

- [ ] Untouched legacy copy exists.
- [ ] Old viewer files and custom code were preserved for reference.
- [ ] Source editor or fork is identified only to the level supported by evidence.
- [ ] Rows, Choices, Points, Requirements, Groups, IDs, CSS, and custom code are inventoried.
- [ ] Representative old builds and totals are recorded.
- [ ] The current ICC Plus target was discovered from the installed rc12 tool or release metadata.
- [ ] `project hydrate` was used only if supported sparse input needed official defaults.
- [ ] `project validate` passes for the migrated final artifact or documented exceptions remain.
- [ ] Legacy workarounds were reproduced before being kept.
- [ ] Public ID compatibility was decided.
- [ ] State-transition tests pass in the target Viewer.
- [ ] Migrated project is saved as a new version.
