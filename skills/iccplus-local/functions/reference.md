# reference

Read this file when the task needs tool discovery rather than project content.

Use `reference` to discover canonical commands, capabilities, fields, schemas, types, guides, parity information, or symbols. Do not guess a field or operation shape when `reference` can answer it.

Common calls:

```bash
iccplus-local reference commands
iccplus-local reference capabilities --brief
iccplus-local reference fields choice --details
iccplus-local reference schema structure-ops
iccplus-local reference types
iccplus-local reference guide automation
iccplus-local reference parity
iccplus-local reference symbols
```

Use `reference` before authoring when the requested field or schema is unfamiliar. Use `inspect` instead when the question is about what exists in a specific project.

For the full command tree, see `../../../docs/CLI_REFERENCE.md`.
