# project

Read this file for serialization, interchange, fragments, IDs, and build strings.

Canonical paths:

```text
project format
project export
project fragment export|import
project ids export|from-titles
project build-summary
project build-string
```

These commands are interchange helpers. They are not alternate authoring paths.

Use `project format` when the task is formatting project JSON. Use export and fragment operations when moving project data. Use ID helpers for ID interchange or derivation. Use build-summary and build-string for the corresponding ICC Plus serialization forms.

For content edits, use `structure`, `rules`, or `style` instead.

See `../../../docs/CLI_REFERENCE.md`, `ID_GUARANTEES.md`, and `BUILD_SYSTEM.md`.
