# media

Read this file when the task is about the assets themselves rather than assigning ordinary project style.

Canonical paths:

```text
media image import|clear
media crop image|field
media font list|add|remove
media sound import
media probe
```

Use `media` to import or clear images, create crops, manage fonts, import sound, or probe an asset. Use `style` to assign normal visual properties to Rows or Choices.

Image compression is automatic for local and embedded images. Do not add a manual compression pass to normal media or style workflows unless a task specifically concerns compression diagnostics.

See `../../../docs/VISUAL_WORKFLOW.md` and `ASSET_COMPRESSION.md`.
