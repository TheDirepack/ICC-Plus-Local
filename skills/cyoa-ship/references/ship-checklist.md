# Ship checklist

- [ ] `iccplus-local project validate` is clean for the final artifact or known exceptions are documented.
- [ ] Full-build runtime tests pass.
- [ ] Correct official web or local template was selected.
- [ ] Generated package loads.
- [ ] Points and major Requirements work in the package.
- [ ] Build save works when enabled.
- [ ] Choice Import works when enabled.
- [ ] Backpack works when enabled.
- [ ] Final hosted URL was checked for web builds.
- [ ] External assets have no unexpected network failures.
- [ ] Release package passes basic contrast, state-cue, target-size, and text-alternative checks where relevant.
- [ ] Static edition was checked separately when one is shipped.
- [ ] Static output exposes or explains interaction-dependent content rather than silently omitting it.
- [ ] Final images were loaded before capture or export.
- [ ] Asset source or credit requirements are satisfied.
- [ ] CYOA, Viewer, ICC Plus Local, ICC Plus target, and pinned engine-source versions are recorded.
- [ ] The release project was rebuilt from authoritative source when a compiler exists.
- [ ] No release-content fix was made only by hand-editing generated project.json.
