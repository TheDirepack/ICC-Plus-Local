# Develop checklist

- [ ] Current artifact and working state refer to the same project version.
- [ ] Premise, player contract, completion rule, and non-goals are still current.
- [ ] Current pass has one bounded purpose.
- [ ] Invariants that must not change are listed.
- [ ] Relevant source boundaries and claim labels are known.
- [ ] The correct high-level skill or ICC Plus Local function guide is being used.
- [ ] Representative work was calibrated before a large batch.
- [ ] Local tests for the pass were run.
- [ ] Global budgets, IDs, terminology, requirement reachability, and completion rules affected by the pass were checked.
- [ ] Additions, edits, removals, and unresolved items were recorded.
- [ ] Working state was updated.
- [ ] A coherent checkpoint exists when the pass changed the artifact.
- [ ] Reusable generators, validators, and test helpers live under /CYOA/tools rather than revision folders.
- [ ] Generated project output remains disposable and reproducible from the authoritative source.
