# CYOA new skills

There is one general installed skill for ICC Plus Local:

- `iccplus-local/SKILL.md`

That skill routes work to focused Markdown guides under `iccplus-local/functions/`. Those files are not separate installed skills and intentionally have no skill front matter.

The function guides map directly to the 11 canonical ICC Plus Local commands:

```text
reference.md
inspect.md
generate.md
build.md
structure.md
rules.md
style.md
play.md
template.md
media.md
project.md
```

Start with `iccplus-local/SKILL.md`. It tells the agent which function guide to read for the current task.
