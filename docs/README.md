# ICC Plus Local documentation

The active ICC Plus Local documentation is in this directory.

Agent operation starts with `../skills/iccplus-local/SKILL.md`. That is the single general skill. It routes each task to a focused guide under `../skills/iccplus-local/functions/`.

For player-view details, use `PLAY_STRUCTURE.md`. For playtesting workflows, use `GAMEPLAY_RUNNER.md`. For the command surface, use `CLI_REFERENCE.md`.

The function guides are intentionally short. Use these full documents when a task needs field-level details, recipes, schemas, coverage information, or release evidence.
