# Using the CYOA skills

The skill set is intentionally compressed.

## Native ICC Plus 2 work

Use `skills/iccplus-local/SKILL.md` for project inspection, creation, editing, styling, media work, validation, hydration, building, serialization, and player-safe mechanical testing. Read only the matching function guides under `skills/iccplus-local/functions/`.

Do not recreate separate `cyoa-create`, `cyoa-edit`, `cyoa-look`, or `cyoa-test` skills.

## High-level CYOA work

Use:

- `cyoa-plan` for a new design or major redesign.
- `cyoa-review` for design, content, balance, reachability, usability, and implementation audits.
- `cyoa-migrate` for legacy ICC or ICC Plus 1.x projects.
- `cyoa-develop` when several passes or sessions need one coherent working state.
- `cyoa-ship` for final packaging, hosted/offline checks, static editions, and release records.
- `cyoa-compress` only for exceptional external or legacy asset trees outside the normal ICC Plus Local media path.

The complete guide is under `docs/cyoa/guide/`. The legacy migration reference is under `docs/cyoa/legacy/`.

For prose cleanup, use an external Unslop skill or equivalent pass. Do not apply prose cleanup to code, JSON, schema fields, exact quotations, or compatibility strings.
