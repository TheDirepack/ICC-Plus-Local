# Skill usage

Use `skills/iccplus-local/SKILL.md` as the single ICC Plus Local skill.

It routes work to the matching file under `skills/iccplus-local/functions/`:

- `reference.md` for commands, fields, schemas, types, guides, parity data, and symbols.
- `inspect.md` for read-only project inspection and search.
- `generate.md` for new blank projects.
- `build.md` for ordered phased builds.
- `structure.md` for Rows, Choices, Addons, text, IDs, ordering, moves, and clones.
- `rules.md` for Points, Scores, Requirements, Groups, costs, limits, activation, and gameplay logic.
- `style.md` for styling, widths, templates, images, and presentation.
- `play.md` for player-safe playtesting and audits.
- `template.md` for entity defaults, style presets, and design import or export.
- `media.md` for images, crops, fonts, sounds, and asset inspection.
- `project.md` for formatting, export, fragments, IDs, and Build Form serialization.

Read only the function guides needed for the current task. They are reference files for the one installed skill, not separate skills.

For prose cleanup, this repository recommends the external Unslop skill. It is not bundled here and should not be applied to code, JSON, schema fields, or exact quotations.
